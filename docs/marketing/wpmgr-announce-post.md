🚀 WPMgr has shipped a TON lately, and honestly I didn't expect this for a project that started as a little tool to manage my own client sites.

It grew from your feedback into a full WordPress fleet manager. Every site you look after, one dashboard, and it's in the best shape it's ever been:

💾 Backups that actually restore. Full + incremental, encrypted, scheduled, off-site, with one-click restore and instant DB snapshots.

🔄 Safe fleet updates. Update plugins, themes and core across every site at once. Each one auto-snapshots first and auto-rolls-back if the update breaks the site, so a bad release never leaves a site down.

📈 Uptime + SSL monitoring with downtime alerts. Now it even catches the "white screen" fatal that WordPress serves as HTTP 200, so a broken site actually pages you.

⚡ Performance suite. Page + object cache, unused-CSS removal, minify, WOFF2 fonts, image optimization, and real-user Core Web Vitals, all per site.

🛡️ Security suite. Login 2FA, password policy with breach checking, hardening + login bans, file-integrity checks, and vulnerability scanning against the Wordfence feed.

🗂️ File manager + code editor. Browse, edit, zip and restore files on any managed site straight from the dashboard, with per-file version history. No SFTP.

🧑‍💼 Built for agencies. White-label client reports, a branded client portal, and fleet-wide dashboards for uptime, backups, performance and email deliverability.

Plus dashboard 2FA (TOTP + passkeys), website screenshots, DB + media cleaners, and more.

And because it does all of this from one dashboard, it retires a whole stack of separate plugins and subscriptions:

🗑️ your backup plugin
🗑️ your caching / performance plugin
🗑️ your security + firewall + 2FA plugins
🗑️ your uptime + SSL monitor
🗑️ your bulk-update / management tool
🗑️ your image + font optimizer
🗑️ your file-manager / SFTP plugin
🗑️ your client-reporting plugin

Fewer moving parts on every site, less to pay for, less to break.
