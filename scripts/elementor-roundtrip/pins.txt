# Everything the Elementor round trip downloads, pinned by sha256.
#
# One line per file:  <name> <version> <sha256> <url> [<stored form>]
#   name         wordpress or elementor
#   version      the release the file holds; the harness refuses a site that runs any other
#   sha256       of the downloaded zip, 64 lowercase hex characters
#   url          plain https
#   stored form  elementor lines only, how that version stores a saved tree's scalars:
#                  as_given  booleans, null and strings come back as they went in
#                  strings   every scalar comes back as a string: true as "1", false and
#                            null as ""
#                Measured per version; the round trip requires exactly that form, so a
#                release that changes it turns the run red. A new pin needs a measured form.
#
# The wordpress line is the one WordPress core the round trip boots. Each
# elementor line is a version the round trip runs against: the last 3.20 patch
# (3.20.4), 3.35.9 and 4.3.4. Adding a line adds a version to the matrix. A changed hash is a changed file and fails the run; a new pin
# needs its hash taken from the downloaded file, not from a page that lists it.
