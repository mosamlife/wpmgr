# WordPress cores that scripts/check-page-kses.sh runs the page builder's markup
# through. One core per line:
#
#   <version> <sha256 of the tarball> <url> [<fallback url> ...]
#
# <version> must equal $wp_version inside the tarball (the script checks), so a
# line cannot point at a different release than it claims. Every download is
# verified against the sha256 before anything is extracted; a mismatch is red.
# The sha256 was computed from the download and cross-checked against the sha1
# that wordpress.org publishes beside each tarball.
#
# Why these three:
#   6.2     the oldest WordPress the agent supports ("Requires at least").
#   6.9.10  the last release before core changed how kses reads attribute
#           values (7.0), so the check covers both sides of that change.
#   7.1.3   the current release.
# Moving a pin is a deliberate edit to this file: re-download, compare the
# sha1 that wordpress.org publishes, then paste the sha256.
